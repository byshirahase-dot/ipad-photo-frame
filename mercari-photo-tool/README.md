# メルカリ写真まとめて加工ツール（mercari-photo-tool）

メルカリに出品する写真を、**写真を入れてボタンを押すだけ**でまとめて加工するツールです。
処理はすべてこのMacの中で行います（有料APIやクラウドは使いません）。

## できること

| 処理 | 内容 | オン/オフ |
|---|---|---|
| ① 背景の差し替え | AI（rembg）で商品だけを切り抜き、背景をイブルの画像に置き換えます。元の背景に写った余計な物や影も消えます。毎回ランダムな位置・わずかな回転で切り出すので、同じ見た目になりません。商品の下には柔らかい接地影をつけ、背景の明るさ・色味を商品になじませます。白背景も選べます | ✅ |
| ② 明るさ・色味の自動補正 | 暗さや黄色っぽさを控えめに補正します（実物と色が変わらない程度） | ✅ |
| ③ 中央寄せ・正方形 | 商品が中央に来るよう余白を整えて 1080×1080 にします。商品の大きさは調整できます | ✅ |
| ④ 文字入れ | 「裁断済み」「未使用」「新品」「美品」「サイズ130」などをチェックで選択（自由入力も可）。イブルの柄の上でも読めるよう、帯付きで角に入れます。「1枚目だけ」か「全部」を選べます | ✅ |

- 処理前と処理後を並べて比較できます
- 切り抜きに失敗した写真は「⚠要確認」と表示され、**背景差し替えなしで出し直し**できます
- 出力は `output/日付/`（例: `output/2026-10-25/`）に保存。**元の写真・背景画像は上書きも削除もしません**
- 同じWi-Fi内の **iPhoneのSafariからも使えます**

## 1. はじめての準備（1回だけ）

### 1-1. Python を用意する
次のどちらかが入っていればOKです（どちらも入っていなければ ① がおすすめ）。

1. **Python 3.12**: https://www.python.org/downloads/ から「macOS 64-bit universal2 installer」をダウンロードしてインストール
2. **uv**（入っていれば Python は自動で用意されます）

> Python 3.10〜3.13 に対応しています。

### 1-2. ツールのフォルダを置く
このフォルダ（`mercari-photo-tool`）を `~/Documents/claude-projects/mercari-photo-tool` に置きます。
ターミナルで次を実行すると、GitHub から取ってきて置いてくれます。

```bash
mkdir -p ~/Documents/claude-projects && cd ~/Documents/claude-projects
git clone --depth 1 -b claude/stoic-euler-fmmpgx https://github.com/byshirahase-dot/ipad-photo-frame.git _tmp_download
mv _tmp_download/mercari-photo-tool ./mercari-photo-tool && rm -rf _tmp_download
```

（ブランチが main にマージ済みなら、`-b claude/stoic-euler-fmmpgx` は `-b main` にしてください。GitHub の画面から ZIP でダウンロードして、中の `mercari-photo-tool` フォルダを移動してもOKです）

### 1-3. イブルの背景画像を入れる
`backgrounds` フォルダに、イブルを撮った写真（jpg / png / heic）を入れます。何枚でもOKで、画面で選べます。

- 明るい場所で**真上から**、柄が画面いっぱいに写るように撮ると、きれいに仕上がります
- 1500px 以上の大きめの写真がおすすめ（ランダムに一部を切り出して使うため）
- 入っている `sample_ibul_pink.jpg` は動作確認用の見本です。不要なら削除してください

## 2. 起動のしかた

`mercari-photo-tool` フォルダの **`start.command` をダブルクリック**するだけです。

- ターミナルが開き、しばらくするとブラウザで画面が開きます
- **初回だけ**、必要なソフトとAIモデル（約180MB）のダウンロードで数分かかります（インターネット接続が必要）。2回目からはすぐ起動します
- 初回に「開発元を確認できないため開けません」と出たら、`start.command` を**右クリック →「開く」→「開く」**
- 「受信接続を受け入れますか？」と聞かれたら **「許可」**（iPhoneから使うために必要）
- 終了するときは、ターミナルのウィンドウを閉じます（または Control + C）

---

## 3. 使い方

1. **① 写真をドラッグ&ドロップ**（複数まとめてOK）
2. 処理内容を選ぶ（背景・影の濃さ・商品の大きさ・文字など）
3. **「まとめて処理する」** を押す
4. **② 処理結果**の写真をタップすると、下に「処理前」「処理後」が並びます
   - 切り抜きがおかしい写真 → **「この写真を背景差し替えなしで出し直す」**
   - 背景の切り出し位置を変えたい・設定を変えてやり直したい → **「この写真を今の設定で出し直す」**
5. 保存先は画面上部に表示されます（`output/日付/`）。**③ まとめてダウンロード（ZIP）** でも受け取れます

---

## 4. iPhone から使う

1. Mac で `start.command` を起動したままにします（Mac をスリープさせない）
2. iPhone を **Mac と同じWi-Fi** につなぎます
3. iPhone の Safari で、ターミナルに表示された **「iPhoneで開く」のアドレス**（例: `http://192.168.1.23:7860`）を開きます
   - 画面左下の「📱 iPhoneから使う」を開くと QRコードが出るので、iPhone のカメラで読み取ってもOK
   - アドレスは `http://（Macのローカルホスト名）.local:7860` でも開けます（ローカルホスト名は Mac の「システム設定 → 一般 → 共有」の下の方に表示）
4. 「① 写真を…」をタップ →「写真ライブラリ」から複数選んで「追加」
5. 処理後の写真は、**処理後の画像を長押し →「"写真"に保存」** でカメラロールに保存できます（ZIP は「ファイル」アプリに保存されます）

> 便利ワザ: Safari の共有ボタン →「ホーム画面に追加」で、アプリのように開けます。
>
> つながらないとき: ① Mac とiPhoneが同じWi-Fiか ② Mac の「システム設定 → ネットワーク → ファイアウォール」で Python の接続が許可されているか ③ iPhone の VPN がオフか を確認してください。

家族以外も使うWi-Fiでは、`config.yaml` の `server:` に `username` と `password` を入れると、パスワード付きになります。

## 5. 設定ファイル（config.yaml）

テキストエディットなどで `config.yaml` を開いて編集し、保存したら画面の **「設定ファイル・背景フォルダを再読み込み」** を押すと反映されます（サーバー設定のみ再起動が必要）。

| 項目 | 説明 |
|---|---|
| `text.presets` | 文字のチェックボックスに並ぶ言葉（追加・削除自由） |
| `text.position` | 文字の位置の初期値（左上 / 右上 / 左下 / 右下） |
| `text.text_color` / `band_color` / `band_opacity` | 文字の色・帯の色・帯の不透明度 |
| `text.colors` | 言葉ごとに色を変える（例: 新品だけ赤い帯） |
| `text.font_size` / `layout` | 文字の大きさ、複数のときの並べ方（縦に積む / 1行にまとめる） |
| `text.font_path` | フォント（空欄なら ヒラギノ角ゴシック W6） |
| `defaults.*` | 画面を開いたときの初期値（影の濃さ・商品の大きさ など） |
| `background.*` | 背景の切り出し方（大きさ・回転角度・左右反転） |
| `enhance.*` | 明るさ・色味補正の強さ |
| `segmentation.model` | 切り抜きAIモデル（切り抜きが苦手な商品が多いときは `birefnet-general-lite` を試す） |
| `output.*` | 保存先・サイズ・形式（jpg/png） |

---

## 6. 困ったとき

- **切り抜きがうまくいかない**: 「背景差し替えなしで出し直す」を使うか、`segmentation.model` を `birefnet-general-lite` に変えて再起動。商品と背景の色が近いと失敗しやすいので、撮影時に背景と違う色の布の上に置くと改善します
- **起動しない / すぐ閉じる**: ターミナルに出ているメッセージを確認。Python が無いと表示されたら「1-1」を実施
- **うまく動かなくなった**: `mercari-photo-tool` の中の隠しフォルダ `.venv` を削除して `start.command` をダブルクリック（セットアップをやり直します）
- **処理が遅い**: 1枚あたり数秒かかります。写真が大きい場合は自動で縮小して処理します

## 開発者向け

```bash
.venv/bin/python -m pip install pytest
.venv/bin/python -m pytest          # 全テスト（AIモデルを使うテストを含む）
.venv/bin/python -m pytest -m "not slow"   # モデルを使わないテストだけ
```

構成:

```
app.py                  画面（Gradio）
photo_tool/pipeline.py  1枚の処理の流れ（補正 → 切り抜き → 背景合成 → 正方形 → 文字）
photo_tool/segment.py   AI切り抜き（rembg）と失敗判定
photo_tool/background.py 背景の切り出し・なじませ・接地影
photo_tool/enhance.py   明るさ・ホワイトバランス補正
photo_tool/layout.py    中央寄せ・正方形
photo_tool/text_overlay.py 文字入れ
config.yaml             設定ファイル
backgrounds/            背景画像（イブル）
output/                 出力（日付フォルダ）
tools/make_sample_background.py 見本背景の作成
```
