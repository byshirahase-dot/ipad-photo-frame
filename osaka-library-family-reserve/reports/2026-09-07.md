# 図書館予約レポート 2026-09-07

## ⚠️ 今週の結論: サイト側の不具合により全アカウント予約成立0冊

大阪市立図書館OPACの**ログイン処理がサイト側で継続的にエラー**となり、
どのアカウントもログインできず、今週は1冊も予約できませんでした。

- **トップページは正常表示**（`logs/2026-09-07/chonan/01-top.html` = 25KB の完全なHTML）。サイト自体は稼働中。
- しかし**ログイン画面へ遷移すると毎回、汎用のエラーページが返る**
  （`02-login-form.html` 等 = 823バイト・「エラー / このページは表示できません。詳細については、
  サポートまでお問い合わせください。 イベント ID: ...」）。
  これはWAF/エッジ側のアクセス拒否・障害ページで、**当システムのコードやOPACの画面構造変更が原因ではない**
  （トップは通常どおり描画され、ログインの遷移先だけがエラーを返す）。
- **アクセスは丁寧に・再実行1回のルールを厳守**: mom は2回（初回＋再実行1回）、chojo・chonan は各1回試行。
  いずれも同一のエッジエラーで、site-wide（アカウント非依存）と確認できたため jinan は試行せず中止した。
  運用ルール（「サイト構造変更が疑われる場合は修正せず報告」）に従い、コードは一切変更していない。
- **state は無傷**: 失敗はすべてログイン段階（カート・予約操作の前）で発生。index.js は batchOk 時のみ
  state を書き込む設計のため、progress/reserved/queue/_expanded は一切変更されていない
  （`git status` で確認済み。今週の予定本は来週の通常実行でそのまま予約される）。
