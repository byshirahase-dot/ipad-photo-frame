# 絵本ナビ枠の選書ポリシー（週次セッションが data/ehonnavi_list.csv を拡充する際に従う）

子ども3人は毎週くもんに加えて、この年齢別リストから1冊ずつ予約する。
週次セッションは絵本ナビ（ehonnavi.net）等の年齢別おすすめを Web 検索し、各 age 帯に
正式タイトル・著者・出版社つきで2〜3冊ずつ追記する（order は続き番号）。
**公文リスト(data/kumon_list.csv)に既にある本は入れない**（絵本ナビ独自の本を優先）。

## 全員共通で避ける（ユーザー指定）

- **ヨシタケシンスケ の本は入れない**（2026-07-13）。

## 年齢帯ごとの方針

### age 3（次男）
年齢相応の絵本。色・リズム・繰り返しが楽しい定番絵本。

### age 6（長男）
年長〜小1向けの絵本。物語性のある絵本、少し長めの読み聞かせも可。

### age 10（長女）
**絵本ではなく小学4〜5年生向けの児童書**。10歳・くもんE（モモ／ハリー・ポッター級）を読む上級読者。
- **避ける（ユーザー指定 2026-07-13）**: アニメ・マンガ調の挿絵の軽い児童書シリーズは嫌い。
  例＝都会のトム&ソーヤ／若おかみは小学生!／探偵チームKZ／ふしぎ駄菓子屋 銭天堂（卒業済み）／
  おばけずかん／5分後に意外な結末 系。この手のシリーズは入れない。
- **好む方向**: 挿絵がアニメ/マンガ調でない、文学寄りの質の高い児童書・海外児童文学。
  「10歳 おすすめ 児童書」「小学4年生 文学 本」等で探し、表紙・挿絵の雰囲気も考慮する。
- **岡田淳（作家）が大好き（2026-07-13）**。未読の岡田淳作品を優先的に順次入れる。
  - **既読（入れない）**: びりっかすの神さま。
  - リストに入れ済みの岡田淳作品（単行本の出版社を確認済み）: 二分間の冒険（偕成社）、
    選ばなかった冒険 光の石の伝説（偕成社）、竜退治の騎士になる方法（偕成社）、
    扉のむこうの物語（理論社）、放課後の時間割（偕成社）、夜の小学校で（偕成社）、
    フングリコングリ 図工室のおはなし会（偕成社）、願いのかなうまがり角（偕成社）。
  - **既読（入れない）**: 選ばなかった冒険 光の石の伝説（2026-07-13 申告）。
  - **こそあどの森の物語（理論社・全12巻）**: ほぼ既読だが未読が不明なため2026-07-13に前半5巻
    （①ふしぎな木の実の料理法／②まよなかの魔女の秘密／③森のなかの海賊船／
    ④ユメミザクラの木の下で／⑤あかりの木の魔法）を一括予約済み（長女の台帳に記録＝再予約されない）。
    受取・確認後、**ユーザーが未読巻を教えてくれたら残り（⑥ミュージカルスパイス／⑦だれかののぞむもの／
    ⑧はじまりの樹の神話／⑨ぬまばあさんのうた 等、図書館所蔵分）を追加**する。頼まれるまで残りは予約しない。
    ※OPACの書名は「こそあどの森の物語」で副題は別フィールド。副題だけの書名検索はヒットしないので、
    予約時は「こそあどの森の物語」で検索し副題で巻を特定すること（検索結果はクリックして開く。URL直行は不可）。
  - 公文リストにある岡田淳作品（例: 学校ウサギをつかまえろ＝偕成社）は入れない（公文側で読む）。
  - 岡田淳を読み切ったら、同傾向（挿絵がアニメ調でない上質なファンタジー児童文学）を探す。
