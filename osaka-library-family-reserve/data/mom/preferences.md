## 選書のベース（対象プール）

以下の文学賞の**受賞作・ノミネート（候補）作**、および **それらの作家の他の作品** から選ぶ：

- 芥川賞（芥川龍之介賞）
- 本屋大賞
- 山本周五郎賞
- 日本ミステリー文学大賞（新人賞含む）

新しい回・古い回にはこだわらず、幅広い年代から選んでよい。
大阪市立図書館に所蔵がありそうな一般流通の書籍を選ぶこと（同人誌・入手困難本は避ける）。

### ノンフィクション／エッセイ枠（2026-07-05 ユーザー追加）

フィクションだけでなく、**内省的なノンフィクション・エッセイ・社会学・ケア**も大好き。
基準作: 宮地尚子『傷を愛せるか』（ケア・トラウマ）、岸政彦『断片的なものの社会学』（市井の人々の生活史）。
これらに近い、**人の傷・弱さ・ケア・市井の人生の語り**を静かに見つめる読み物を選書プールに含める。
参考になる書き手・傾向: 岸政彦、宮地尚子、東畑開人（ケア論）、上間陽子（生活史）、伊藤亜紗（当事者・身体）、
最相葉月、ブレイディみかこ 等。紀伊國屋じんぶん大賞・大佛次郎論壇賞・Yahoo!ノンフィクション本大賞なども目安。
毎週4冊のうち **1〜2冊はこの枠から** 入れてよい（残りは上の文学賞フィクション枠）。

## 選書ルール（毎週4冊）

0. **最優先: 読みたい本リスト（`data/mom/wishlist.json`）**
   ユーザーが明示的に「読みたい」と入れた本のプール。毎週の4冊は、まずここから
   （下の除外に該当しないものを）優先して埋める。残った枠を下の賞ベース選書で補う。
   - wishlist の各本は写真OCR由来でタイトル・出版社が不確実なことがある（特に `verify:true`）。
     **queue.json に入れる前に必ずWeb検索で正式タイトル・著者・出版社を確認**し、正確な表記で入れる。
   - 大阪市立図書館に所蔵がなさそう／確認できない本はその週は飛ばし、wishlist には残す
     （翌週以降に再挑戦）。予約が成立した本は recommended.json に載るので自然に外れる。
   - コミック（note:"コミック"）も本人が読みたいものなので予約対象に含めてよい。
   - **`notBefore`（YYYY-MM-DD）付きの本は、その日付以降になるまで選ばない**（例: 一旦キャンセル
     して「約1年後にまた借りたい」本）。今日がその日付以降になったら通常どおり優先候補に含める。

1. **除外**: 次のいずれかに載っている本は選ばない
   - `data/mom/history.csv`（読了・既読申告済み）
   - `state/mom/recommended.json`（過去に推薦・予約済み）
   - `data/mom/queue.json` の残り（前週の未予約分）
2. **評価の反映**: history.csv の rating を見る
   - ★4〜5 の本 → その作家の別作品や、似た傾向（ジャンル・テーマ・読み味）を優先
   - ★1〜2 の本 → その作家・傾向は当面避ける
3. **バランス**: 4冊のうち、同じ作家は最大2冊まで。賞のジャンルもなるべく散らす
   （例: 直木賞系エンタメ2＋本屋大賞系1＋ミステリー1）
4. queue.json には理由を書く: `{ "items": [{ "title": "...", "author": "...", "reason": "○○賞受賞。★5だった『△△』と同じ作家" }] }`

## フィードバックの受け方（ユーザーはチャットで自由に伝える）

ユーザー（母）は毎週のレポートへの返信などで、自由な言葉でフィードバックする。
Cowork の Claude はそれを解釈して以下を更新する：

| ユーザーの発言例 | やること |
|---|---|
| 「『◯◯』はもう読んだ」「それ持ってる」 | history.csv に追記（rating空欄、memo=既読申告）。queue.json にあれば削除 |
| 「『◯◯』面白かった！」「◯◯は最高」 | history.csv に rating 4〜5 で追記（発言の熱量で判断）＋memo |
| 「『◯◯』はいまいち」「途中でやめた」 | history.csv に rating 1〜2 で追記＋memo |
| 「◯◯みたいな本が読みたい」「歴史物を増やして」 | 下の「最近の要望メモ」に追記し、次回から選書に反映 |
| 「◯◯賞はもういい」 | 「最近の要望メモ」に追記し、そのプールの比重を下げる |

- history.csv の形式: `date,title,author,rating,memo`（rating は空欄可）
- 毎週のレポート要約の最後に必ず「📚 来週のお母さんの4冊（候補）」をタイトル・作家・理由つきで
  提示し、「読んだことがある本や感想（★1〜5）があれば返信で教えてください。
  来週月曜の予約前に差し替え・反映します」と添える。
  既読の申告があった本は queue.json から外し、代わりの1冊を選書して補充する
